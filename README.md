# 🏷️ README Badge Maker

A lightweight Python CLI tool for generating Markdown badges for GitHub README files.

## Features

- Create custom README badges
- Generate Markdown automatically
- URL-safe badge text
- No external dependencies

## Run

```bash
python main.py
```

## Example

```text
🏷️ README Badge Maker
===================================

Badge label: Python
Badge message: 100%

📋 Markdown:
![Python](https://img.shields.io/badge/Python-100%25-blue)
```

Copy the generated Markdown directly into your README.

## Built With

- Python
- urllib
- Markdown
